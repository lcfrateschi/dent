  O código de 6 dígitos (MFA é obrigatório para a equipe — é prontuário):

  docker compose exec app npm run demo:codigo

  Imprime o código atual de cada perfil. Ou adicione o segredo ao seu autenticador — o demo:preparar imprimiu o otpauth:// de cada um. Esse script só lê @demo.local e recusa rodar em
  produção; o filtro está na consulta, não num if.
